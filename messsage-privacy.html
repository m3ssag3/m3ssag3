Бид message content-ийг зар сурталчилгаа, profiling эсвэл худалдах зорилгоор ашиглахгүй. Зурвас нь Discord-ийн өөрийн системээр дамждаг тул Discord-ийн privacy terms мөн хамаарна.

5. OAuth login

Website-ийн Sign in/Sign up нь Discord OAuth ашиглаж болно. OAuth-аар Discord таны зөвшөөрсөн scope-д багтах identity мэдээллийг буцаана. MessAge нь таны Discord password, bot token эсвэл client secret-ийг харахгүй, хадгалахгүй.

Sign in болон Sign up нь техникийн хувьд ижил OAuth урсгал: анх удаа орж байгаа Discord ID-д account record үүсгэж, өмнө нь бүртгэлтэй бол existing account-ийг нээнэ. Token солилцоо (client_secret ашигладаг хэсэг) зөвхөн backend server дээр хийгдэнэ; browser нь зөвхөн богино хугацаанд хүчинтэй, зөвшөөрсөн scope-той session token хүлээн авдаг бөгөөд энэ нь client_secret-ийг орлохгүй.

6. Хуваалцах болон third parties

Бид мэдээллийг зардаггүй. Үйлчилгээ үзүүлэхэд шаардлагатай хүрээнд дараах талуудтай дамжиж болно:

  • Discord: Bot gateway, message delivery болон OAuth identity;
  • Hosting/database provider: Bot болон website ажиллуулах infrastructure;
  • MessAge owner/moderator: Report, audit, appeal шийдвэрлэхэд шаардлагатай мэдээлэл;
  • Хууль ёсны байгууллага: Зөвхөн хүчин төгөлдөр хууль ёсны шаардлага гарсан үед.

Third-party үйлчилгээ өөрийн privacy policy-тэй байж болно. Тэдгээрийн үйл ажиллагааг MessAge бүрэн хянахгүй.

Мэдээллийг зорилгодоо шаардлагатай хугацаанд хадгална. Exact retention нь bot-ийн database, abuse case болон support хэрэгцээнээс хамаарч өөрчлөгдөж болох ч бид дараах зарчмыг баримтална:
